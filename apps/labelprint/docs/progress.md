## 2026-09-03 - Task: 最终整支审查修复轮（8 项问题一次处理完）

### What was done

- 修了一个最危险的设计失误：桌面上那个给实验室人员自查用的"标签打印 - 自检"
  图标，原来点一下会把**整个实验室所有打印机**都暂停、清空排队作业、再恢复
  ——包括同事正在用的共享激光打印机。现在改成只作用于标签打印机自己
  （Brady BBP12），别的打印机在自检过程中完全不受影响。
- 顺手堵上一个连带的漏洞：以前"暂停"这一步只要没报错就算成功，哪怕其实
  根本没暂停成功也会被当成"已暂停"，之后照样把数据发给打印机，有极小概率
  打出意外的实物标签。现在暂停后会额外核实一遍是不是真的停下来了，没停下
  就直接判失败，绝不会带着"以为暂停了、其实没有"的错误状态继续往下走。
- 修了一个数据会丢失的隐患：打印历史数据库原来存在代码目录里面，按 README
  原来写的升级步骤操作（先删旧代码再放新代码）会连数据库一起删掉。现在数据
  库单独放一个不会被代码更新触碰到的目录，目标机上原有的数据已经安全搬过去，
  搬迁前后逐字节比对完全一致，没有丢失任何记录。
- 修了一个会导致重复打印的问题：打印其实已经成功送出去了，但如果这时候写
  历史记录这一步恰好出错（比如两个人同时在打），页面会误报"打印失败"，
  容易让人误会没打成功而再点一次，同一批标签就被打印两遍。现在这种情况会
  正确显示"已送出"，只是附带提示一句历史记录没记上，不会误导用户重打。
- 修了双击"打印"按钮会真的打印两遍的问题（已用真实浏览器操作复现确认）：
  现在点一下打印后按钮会立即变灰，请求处理完才恢复，不管是真的手滑双击
  还是网页卡顿时连点，都只会送出一次。
- 一次要打印超过 100 张时，现在会先弹窗确认张数，需要用户点确定才会真的
  送出，防止填错行数或份数时一次性浪费大量标签纸。
- 表格里如果有用公式算出来的数字（比如浓度比值常见的 =A2/B2 写法），以前
  可能会把 1.83 这种数打印成 1.8299999999999998 这种带一长串小数点的怪数字
  （Excel 内部计算的浮点误差），现在会自动清理成正常的 1.83，不影响正常
  的整数、小数值。
- 删掉了一份已经确认过时、且自己带着"打印机被拔线也会报正常"这个假象的
  旧验证工具副本（从未在自检流程里被用到，纯属遗留死代码），避免以后有人
  误用这份已经过时的副本。
- 开发机上的标签预览效果现在会优先使用真正的微软雅黑字体（如果这台机装了
  Office 全家桶的话），跟目标机上用的是同一款字体，减少"开发机看着没问题、
  目标机才发现排版有毛病"的情况。
- 另外三个很便宜的小修补：上传的表格文件加了 10MB 大小上限（防止把这台
  同时跑着 MariaDB、NanoDrop 的电脑内存吃满）；防火墙规则里补了一句说明，
  写清楚这条规则是整个服务唯一的门禁，提醒以后调整防火墙的人三思；仓库里
  三个换布局前留下的空文件夹清理掉了。
