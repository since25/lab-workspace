# 物料管理：标签打印字段与权限方案调研报告（TASK-93）

> 调研目标：针对实验室物料管理下游接入标签打印场景，明确个人物料管理诉求、数据上传与录入途径、字段校验规则与容错机制、必要打印字段与 30×15 mm 版面适配、权限与数据隔离方案，并提供切实可行的分期开发路线。

---

## 1. 业务背景与现状分析

### 1.1 现有物料台账与标签打印现状
- **现有部门物料（`material_items`）**：主要服务于大宗采购入库、验收登记与部门公用耗材台账。现有标签打印已接入 `materials` 来源，包含字段：名称、物料编码、规格型号、品牌、部门、单位。
- **现有标签纸张规格**：Brady BBP12（及后续 POSTEK C168）双列卷筒纸，单格物理尺寸约 30 × 15 mm（300 dpi 下为 351 × 178 点）。
- **痛点与缺口**：
  1. 科研人员在领用原装试剂或大包装原料后，通常会在实验台进行二次配制、稀释或小管分装（如抗体母液、感受态细胞、引物母液、各种缓冲液等）。
  2. 此类分装管或个人保存的小样目前缺乏「个人物料」管理台账。
  3. 现有部门物料缺少实验操作中最核心的四个物理量：**配制/分装日期**、**实际浓度**、**分装体积**、**保管人**。
  4. 标签打印权限需要与个人隐私/数据隔离挂钩，避免全所人员混淆打印或乱打他人私有样品。

## 2. 数据上传与录入途径

为满足科研人员在不同实验场景下的使用习惯，规划三种互补的录入与上传途径：

### 2.1 途径一：Excel / CSV 批量导入（离线批量分装场景）
- **适用场景**：一次性配制几十管引物、稀释一整个抗体盒或批量合成产物入库。
- **操作流程**：
  1. 在「个人物料」页面提供「下载标准模板（Excel/CSV）」按钮；
  2. 用户在本地填写表头对应的字段（试剂名称、浓度、体积、管数、配制日期、保管人、存放位置、原物料编码、备注）；
  3. 页面拖拽上传文件，服务端接口执行解析与预检（Dry-run），返回：校验通过行数、格式警告行数、格式错误行数及明细；
  4. 用户点击「确认导入」，数据写入 `personal_materials`；
  5. 导入完成弹窗中提供快捷按钮「**一键勾选本批次并前往标签打印**」，无缝串联打印流。

### 2.2 途径二：在线表单快捷录入（单条日常配制场景）
- **适用场景**：科研人员当天随手配制一两管缓冲液或解冻分装单管试剂。
- **操作流程**：
  - 在「个人物料」主页点击「新增分装」，弹出轻量级录入抽屉/Modal；
  - 保管人默认自动填充当前登录用户姓名；
  - 配制日期默认自动填充当天日期；
  - 提供常用浓度与体积单位下拉快捷点选（如 `mg/mL`、`μL`）；
  - 保存后该条目置顶展示，行末带「打印标签」快捷按钮。

### 2.3 途径三：从公共物料/库存台账“一键登记分装”（领用联动场景）
- **适用场景**：在「部门物料」或「耗材库存」领用原物料后直接分装。
- **操作流程**：
  - 在部门物料或耗材库存列表操作列新增「登记分装」操作；
  - 自动继承原物料名称、物料编码、品牌、规格等基础元数据；
  - 用户只需输入本次配制的分装体积、浓度、管数；
  - 既完成了公共库存的领用记录，又生成了科研人员自己的分装试剂标签打印源。

## 3. 字段口径与格式校验规则

### 3.1 核心字段定义与校验标准

| 字段标识 | 业务含义 | 必填 | 数据类型与长度 | 校验规则与规范化处理 | 错误/警告行为 |
|---|---|---|---|---|---|
| `name` | 试剂/分装名称 | **是** | `text (1~100)` | 自动 trim 首尾空格；不可纯为空或纯符号。 | 拦截并提示“请输入有效试剂名称” |
| `keeper` | 保管人/配制人 | **是** | `text (1~30)` | 默认填充当前用户姓名；允许手动指定协助人。 | 拦截并提示“保管人不可为空” |
| `prepared_on` | 配制/分装日期 | **是** | `date` | 格式规范为 `YYYY-MM-DD`。支持 `YYYY/MM/DD`、`YYYY.MM.DD` 自动格式化。日期不得晚于今天 3 天以上，不得早于 2000-01-01。 | 格式错误时拦截；异常日期提示警告 |
| `concentration` | 浓度（含单位） | 否 | `text (1~40)` | **推荐正则**：`^(\d+(\.\d+)?)\s*(mg/mL|ug/mL|μg/mL|ng/uL|ng/μL|M|mM|uM|μM|nM|X|x|%)$`<br>自动归一化：`ug` → `μg`，`ul` → `μL`，去空格。<br>特殊文本允许：若输入“原液”、“饱和液”、“未测”，允许通过。 | 若为无法辨识的非法字符组合，标记警告放入待核对 |
| `volume` | 分装/剩余体积 | 否 | `text (1~30)` | **推荐正则**：`^(\d+(\.\d+)?)\s*(uL|μL|mL|L)$`<br>自动归一化：将 `ul`、`microliter` 统一纠偏为 `μL`。 | 无法识别时保留原样并提示警告 |
| `tube_count` | 分装管数 | 否 | `integer` | 整数，范围 1–1000，默认 1。 | 非整数或 <=0 自动兜底设为 1 |
| `location` | 存放位置 | 否 | `text (1~60)` | 自由文本，例如“-20℃ 冰箱 2层”、“4℃ 层析柜 A3”。 | 超过 60 字截断提示 |
| `expiry_on` | 有效期/失效日 | 否 | `date` | 格式 `YYYY-MM-DD`，可选。必须晚于 `prepared_on`。 | 若早于配制日期提示警告 |
| `remarks` | 备注说明 | 否 | `text (1~200)` | 溶剂成分、纯化批次、实验注意事项等。 | 超长截断 |

### 3.2 容错与待核对（`needs_review`）机制
参照系统现有 `cell_inventory` 的成熟设计：
- 在 Excel / CSV 批量导入时，若某行数据的名称存在，但浓度、日期或体积存在轻微格式瑕疵（如 `10mg/ml` 缺少标准空格，或日期格式为 `20261024`）：
  - 系统**不直接粗暴终止整个导入事务**；
  - 将原始文字保存在 `*_raw` 字段中；
  - 自动打上 `needs_review = true` 标记，并写入 `review_reason`（例如“浓度单位未标准化”）；
  - 用户可在列表顶部通过「待核对」筛选项快速定位并在线修正，修正后方可批量勾选打印，兼顾数据合规与业务效率。

## 4. 30×15 mm 版面排版与自适应策略

双列卷筒纸（Brady BBP12 / POSTEK C168）单格物理尺寸约 30 × 15 mm，有效画布绘制区扣除四周 15 点留白后约 321 × 150 点。

### 4.1 字段优先级与排布推荐
- **第 1 行（标题大字）**：`name`（试剂名称），字号 30–34 pt（遇超长自动缩至 18 pt），最多排 2 行，垂直居中对齐；
- **第 2 行（核心理化参数）**：`concentration` 与 `volume`，合并同排展示，例如：`10 mg/mL  500 μL`，字号 20 pt；
- **第 3 行（时间与归属）**：`prepared_on` 与 `keeper`，例如：`2026-10-24  张三`，字号 20 pt；
- **备选行**：`location`（位置），例如：`-20℃ A2`。

### 4.2 结合 TASK-90 自定义模板引擎
利用已上线的 `label_templates` 模板编辑器：
- 管理员可创建「个人试剂管标准模板」，预置字段顺序为：`name` → `concentration` → `volume` → `prepared_on` → `keeper`；
- 前缀自定义配置为：`浓度：`、`体积：`、`日期：`、`人：`；
- 打印时自动锁定字段顺序与前缀，科研人员无需每次手动逐项勾选。

## 5. 权限管理与数据隔离方案

### 5.1 权限层级模型
1. **系统功能权限**：
   - 沿用 `users.label_print_enabled` 开关。由管理员在「账号管理」中分配。未开启者无标签打印导航与接口权限（统一 403）。
2. **数据查看与打印权限**：
   - **公共物料（部门物料/耗材库存）**：沿用部门隔离规则（`MATERIAL_DISPLAY_DEPARTMENTS_JSON`），同部门人员可查看、勾选并打印。
   - **个人物料（`personal_materials`）**：
     - **普通成员（Role: member）**：默认**只能查看、维护和打印自己名下**的个人物料（`WHERE owner_id = session.user.id`）。
     - **部门管理员 / 超级管理员（Role: admin）**：可切换查看全员个人物料（用于代打标签、交接盘点或离职归档）。

### 5.2 接口与审计策略
- 所有打印作业统一记录入 `label_print_jobs`，并记录 `user_id`、`source`（记 `personal_materials`）、`item_ids`、`template_id`。
- 保证打印操作可追溯，防范标签纸与碳带耗材滥用。

## 6. 实施路线与数据库模型规划

### 6.1 数据结构设计（待立项实施）
```sql
CREATE TABLE personal_materials (
  id                  serial PRIMARY KEY,
  owner_id            integer NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  material_id         integer REFERENCES material_items(id) ON DELETE SET NULL, -- 可选关联部门物料原品
  name                text NOT NULL,                                             -- 试剂/分装名称
  concentration       text NOT NULL DEFAULT '',                                  -- 浓度（如 10 mg/mL, 100 μM）
  volume              text NOT NULL DEFAULT '',                                  -- 体积（如 500 μL, 10 mL）
  tube_count          integer NOT NULL DEFAULT 1 CHECK (tube_count >= 1),        -- 分装管数
  prepared_on         date NOT NULL DEFAULT CURRENT_DATE,                        -- 配制/分装日期
  expiry_on           date,                                                      -- 有效期（可选）
  location            text NOT NULL DEFAULT '',                                  -- 存放位置
  remarks             text NOT NULL DEFAULT '',                                  -- 备注
  needs_review        boolean NOT NULL DEFAULT false,                            -- 是否待核对
  review_reason       text NOT NULL DEFAULT '',                                  -- 待核对原因
  is_archived         boolean NOT NULL DEFAULT false,                            -- 是否归档/耗尽
  import_batch_id     integer REFERENCES import_batches(id) ON DELETE SET NULL,  -- 导入批次
  created_at          timestamptz NOT NULL DEFAULT now(),
  updated_at          timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX personal_materials_owner_idx ON personal_materials(owner_id, is_archived);
```

### 6.2 分期实施建议
1. **第一期（调研完成，即本阶段 TASK-93）**：明确字段、上传途径、校验规则、权限与版面规范，形成方案文档，待用户决策开工时机。
2. **第二期（台账与数据层）**：执行 SQL 迁移创建 `personal_materials`，在前端新增「个人物料」维护抽屉与 Excel/CSV 上传导入组件。
3. **第三期（打印打通）**：在 `label-sources.ts` 中注册 `personal_materials` 数据源，支持按在库管数倍增打印，与自定义模板全面打通。
