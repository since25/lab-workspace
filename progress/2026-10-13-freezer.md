# 2026-10-13 新增冰箱管理

## What was done

- 新增「冰箱管理」页面（导航第二项）：温度标签页 全部 / -80℃ / -20℃ / 4℃（带数量）；「样品 / 容器」两个视图。
- 结构为 冰箱 → 容器 → 样品：容器分盒子、框两类，有名称和备注，不设规格；位置记 冰箱、第几层（必填）、第几个架子、架内第几格（后两项选填，框或大箱子可不填）；样品只定位到容器，一条 = 一管。
- 样品字段：样品信息、位置、项目号、样品类型、备注、存入日期。
- 批量存入：选已有容器或当场新建（同一事务），每行一管，可从 Excel 粘贴「样品信息/项目号/样品类型/备注」，空列用统一填写，预览后提交，一次最多 500 管。
- 批量取出 / 转移：勾选后取出（保留记录，可按状态查）或转移到已有/新建容器，可写用途说明；已取出的样品转入容器即放回。每管流转历史（存入、修改、转移、取出，含原位置/新位置/说明）在编辑弹窗中查看。
- 权限：容器和样品归创建人，普通用户只看自己的；管理员有「全部人员（只读）」视图，可按存放人筛选，不能修改他人数据。冰箱清单由管理员在「管理冰箱」中维护（停用 / 删除空冰箱）。盒子登记到已被占用的 冰箱/层/架/格 时只提示，不透露对方信息。
- 数据库迁移 `004_freezer.sql`：新增 `freezers`、`freezer_containers`、`freezer_samples` 三张表，不改动现有表。
- 首页增加「冰箱管理」行；操作记录页增加新操作的中文名称。
- 文档：数据模型、接口、决策、架构权限、README。
