# TASK-90 标签打印：模板编辑器

## What was done

- 迁移 `016_label_templates.sql`（用户已确认）：新表 `label_templates`（来源、名称、基于的内置模板、名称/字段字号、行距、有序字段与前缀、软删除），`label_print_jobs` 加可空列 `template_id`。只新增，不改已有数据。
- 标签服务：`render.custom_style()` 在内置模板上套用字号与行距（范围 12–72 / 10–48 / 0–20 点，缩字号下限取内置下限与设定值较小者）；`/api/preview`、`/api/print` 接受可选 `style`，不合法返回 400。不传 `style` 时内置模板输出不变。
- 工作台：
  - `lib/label-templates.ts`：模板参数校验、列表、按 `template_id` 解析为「内置模板 + style + 字段顺序 + 前缀」；`labelRows` 支持自定义前缀。
  - 接口：`GET /label-print/templates`（按来源列出，能打印的人可读）、`/admin/label-templates`（增、查）、`/admin/label-templates/:id`（改、删=隐藏）；预览接口接受管理员的 `draft`；打印接口写 `template_id`，`template` 记 `来源:custom-<编号>`。
  - 页面：新增「管理 → 标签模板」（复制内置模板、滑块/数字调字号与行距、勾选字段与上移下移、前缀、按关键字换样本预览、保存/编辑/复制/删除）；「标签打印」页按来源显示自定义模板，选中后字段锁定为模板顺序。
- 测试与脚本：pytest 新增 4 条；Vitest 新增 `label-templates.test.ts` 5 条（含全部迁移按序执行）；`check-label-print-ui.mjs` 补模板接口的模拟返回。
- 文档：`docs/label-print.md`（自定义模板一节）、`docs/data-model.md`（label_templates）、`docs/api-contract.md`（新接口与 `template_id`/`style`/`draft`）。
