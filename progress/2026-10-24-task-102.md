# TASK-102 新增 CSV 标签打印功能（方案 ② 台账固化型）

## What was done

- **数据库迁移**：
  - `db/migrations/017_label_custom_csv.sql`：
    - 新增 `label_custom_batches` 表（存储用户上传的 CSV 批次信息、原始文件名、表头字段数组 `headers`、行数 `row_count`、归属用户 `created_by`、创建时间）；
    - 新增 `label_custom_items` 表（存储批次各数据行，`batch_id` 级联外键，`data JSONB` 存储各列键值，`row_index` 记录物理行序）；
    - 更新 `label_templates` 表的 `source` CHECK 约束，扩充放行 `'cells'` 与 `'custom'`。
- **服务端模块与 API**：
  - `apps/web/src/lib/label-custom-csv.ts`：
    - `parseAndSaveCustomCsv`：解析上传 CSV 内容（自动去除首尾 BOM、利用现成 `parseCsv` 正确处理引号转义与字段内换行），批量入库 `label_custom_batches` 与 `label_custom_items`；
    - `listCustomBatches`：按用户隔离查询批次列表（普通成员查自己，管理员查全站）；
    - `getCustomBatch`：读取指定批次或最新批次。
  - `apps/web/src/app/api/v1/label-print/custom-batches/route.ts`：
    - `GET`：获取用户可见的 CSV 批次列表；
    - `POST`：接收 CSV 上传文本与文件名，解析固化入库并返回新创建的批次。
- **数据源适配**：
  - `apps/web/src/lib/label-sources.ts`：
    - `SourceKey` 新增 `'custom'`；
    - `listSourceItems` 针对 `custom` 动态从 `label_custom_batches` 读取批次表头并构造成字段选项（首列默认作为大字标题）；从 `label_custom_items` 读取数据并展开为标准表格结构；
    - `getSourceItems` 适配 `custom` 来源按 ID 列表拉取打印行；
    - `parseSourceFields` 对 `custom` 动态表头放行合法非空字段。
- **前端交互与状态维护**：
  - `apps/web/src/app/(app)/label-print/LabelPrintClient.tsx`：
    - 来源选项卡新增「自定义 CSV」；
    - 切换到「自定义 CSV」时，提供「当前 CSV 批次」下拉切换框与「上传新 CSV」按钮（文件选择器过滤 `.csv`）；
    - 上传完成后自动选中新批次并加载其动态字段与表格列；
    - 字段配置区根据批次表头动态渲染复选框，首列作为大字标题，其余勾选列逐行排布并支持拖拽调整；
    - 表格勾选记录联动双列（two-up）位图画布预览与出纸打印。

## 2026-10-24 返工：解决上传 CSV 仅显示前 4 列问题

- **问题原因**：`apps/web/src/lib/label-sources.ts` 中 `custom` 来源将 `columns` 硬编码为 `headers.slice(0, 5)`，且前端表格样式强加了 `text-col`（最小宽 220px），导致列数受限及多列时被截断挤出视口。
- **改动内容**：
  1. `apps/web/src/lib/label-sources.ts`：移除 `headers.slice(0, 5)` 限制，直接将 CSV 全部表头作为 `columns`（`headers.map((h) => ({ key: h, label: h }))`），支持任意列数自适应展示；
  2. `apps/web/src/app/(app)/label-print/LabelPrintClient.tsx`：为表格表头和单元格增加 `whiteSpace: "nowrap"`，去除对动态 CSV 列强加的固定最小宽，多列时借助容器 `.table-wrap` 横向平滑滚动；
  3. `apps/web/scripts/serve-task-92-preview.mjs`：同步放开 preview 服务中 `columns` 切片逻辑，预置批次扩展为 7 列；
  4. `apps/web/scripts/test-task-102-ui.mjs`：扩展测试用例为 7 列与上传 8 列，断言全部表头列均有渲染并在证据库更新截图。
- **测试结果**：
